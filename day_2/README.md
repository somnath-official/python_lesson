# Day 2 — Python Data Types and Type Conversion

Covers Python's built-in data types, mutable vs immutable types, and converting values from one type to another.

## Topics Covered

- Built-in data types — numeric (`int`, `float`, `complex`), `bool`, `str`
- Sequence types — `list`, `tuple`, `range`
- Mapping, set and binary types — `dict`, `set`, `frozenset`, `bytes`, `bytearray`, `memoryview`
- `NoneType`
- Mutable vs immutable types
- Type conversion — implicit vs explicit (`int()`, `float()`, `str()`, `bool()`, `list()`, `tuple()`, `set()`, `dict()`, `complex()`)
- `input()` always returns a string
- Handling conversion errors with `try`/`except`
