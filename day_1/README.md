# Day 1 — Python Variables and Printing

Introduction to Python basics: printing output, working with variables, taking user input, and formatting strings.

## Topics Covered

- `print()` — printing text and variable values to the console
- Variables — assigning and referencing values
- `input()` — reading user input
- f-strings — embedding variable values inside strings
- `len()` — getting the length of a string
