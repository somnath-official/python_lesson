# Day 3 — Python Operators and Control Flow

Covers Python operators, conditional statements, loops, and jump statements to control the flow of a program.

## Topics Covered

- Operators — arithmetic, comparison, assignment, logical, bitwise, membership, identity, unary
- Conditional statements — `if`, `if-else`, `if-elif-else`, nested `if`
- Looping statements — `for`, `while`
- Jump/transfer statements — `break`, `continue`, `pass`

## Notebooks

| Notebook | Description |
| --- | --- |
| `python_operators.ipynb` | Core lesson covering all operator types with examples |
| `python_control_flow.ipynb` | Core lesson covering conditionals, loops, and jump statements |

## How to Run
