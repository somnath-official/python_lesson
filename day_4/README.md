# Day 4 — Python Lists

Covers Python lists: an ordered, mutable collection used to store multiple values in a single variable, from creation and indexing through slicing and nested lists.

## Topics Covered

- Creating lists — ordered collections that can hold mixed data types
- Accessing elements — zero-based indexing and negative indexing from the end
- Changing elements — lists are mutable
- Adding elements — `append()`, `insert()`, `extend()`
- Removing elements — `remove()`, `pop()`, `del`
- List slicing — `list[start:stop:step]`, including reversed slicing with `[::-1]`
- Useful list functions — `len()`, `max()`, `min()`, `sum()`
- Useful list methods — `count()`, `index()`, `sort()`, `reverse()`
- Checking membership — `in` and `not in`
- Looping through a list — `for` loops, with indexes via `enumerate()`
- Nested lists — lists containing other lists
